# Тапсырмалар — MIT App Inventor нұсқасы

Қосымшаның қарапайым нұсқасы: [`Tapsyrmalar.aia`](Tapsyrmalar.aia).

## Ашу

1. https://ai2.appinventor.mit.edu сайтына Google аккаунтымен кіріңіз.
2. **Projects → Import project (.aia) from my computer** → `Tapsyrmalar.aia` файлын таңдаңыз.
3. Телефонда **MIT AI2 Companion** қосымшасын ашып, **Connect → AI Companion** арқылы QR-кодты сканерлеңіз.
4. APK керек болса: **Build → Android App (.apk)**.

## Экрандар

| Экран | Мазмұны |
|---|---|
| `Screen1` | Тапсырмалар тізімі, іздеу жолы (ListView сүзгісі), маңыздылығы бойынша сұрыптау, статистика |
| `AddScreen` | Жаңа тапсырма: атауы, маңыздылығы, мерзімі (DatePicker) |
| `DetailScreen` | Өзгерту, орындалды деп белгілеу, жою (растау диалогымен) |

Деректер `TinyDB` ішінде (`Namespace = Tapsyrmalar`, тег `tasks`) сақталады. Әр тапсырма — тізім:
`[атауы, маңыздылығы, мерзімі, орындалды ("1" / "0")]`.

Тексерулер: бос атау, 3 таңбадан қысқа немесе 60 таңбадан ұзын атау, өткен күнді мерзім ретінде таңдау — `Notifier` арқылы хабарлама шығады.
